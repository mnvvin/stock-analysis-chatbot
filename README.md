# 📈 Alpha Analyst: Stock Analysis Chatbot

This is a professional, full-stack stock analysis chatbot designed for scalability and maintainability. It is built using **FastAPI** (Python backend) and **React** (Frontend), strictly following **Clean Architecture** and **Domain-Driven Design (DDD)** principles.

The backend leverages the **Gemini API** to provide intelligent, contextual analysis based on real-time stock data (currently mocked for **AAPL**, **GOOG**, and **TSLA**).

---

## 🏗️ Architecture Overview

The project is structured to ensure a clear separation of concerns, making it highly modular and testable:

1.  **Domain/Application (Core):** Contains the core business logic (`ChatService`) and defining data contracts (Entities like `StockData`). This layer is framework-agnostic.
2.  **Infrastructure (External):** Handles external dependencies, including the FastAPI web server, the `MockStockRepository` for fetching data, and the `GeminiAnalyzer` for AI communication.
3.  **Presentation (Frontend):** The React UI, which manages the user interface and communicates solely with the FastAPI API.

---

## 🚀 Getting Started

To run the application, you must execute the **backend (FastAPI)** and the **frontend (React)** concurrently in two separate terminal windows.

### Prerequisites

Please ensure you have the following installed on your system:

* **Python 3.8+** (for FastAPI)
* **Node.js (LTS)** and **npm** (for React/Vite)

### Step 1: Set up the Backend (FastAPI)

1.  **Navigate** to the `backend` directory in your first terminal:
    ```bash
    cd stock-analyzer-chatbot/backend
    ```

2.  **Create and activate** the Python virtual environment:
    ```bash
    python -m venv .venv
    # On Windows: .venv\Scripts\activate
    # On macOS/Linux: source .venv/bin/activate
    ```

3.  **Install** the required dependencies:
    ```bash
    pip install fastapi uvicorn pydantic requests
    ```

4.  **Run the Backend Server:**
    ```bash
    uvicorn main:app --reload --host 0.0.0.0 --port 8000
    ```
    The FastAPI server is now running on `http://127.0.0.1:8000`. **Keep this terminal window open.**

### Step 2: Set up the Frontend (React)

1.  **Navigate** to the `frontend` directory in a **new terminal window**:
    ```bash
    cd ../frontend
    ```

2.  **Install** the Node.js dependencies:
    ```bash
    npm install
    ```

3.  **Run the Frontend Server:**
    ```bash
    npm run dev
    ```
    The React frontend will typically open at `http://localhost:5173`.

## 💬 Usage

1.  Open the frontend URL (e.g., `http://localhost:5173`) in your web browser.
2.  Type a query asking for an analysis on one of the supported tickers:
    * `What is the current status of AAPL?`
    * `Tell me the latest price for GOOG.`
    * `Analyze TSLA's performance today.`

The chatbot will extract the ticker, fetch the mock data from the backend, and return a contextual, professional analysis generated by the AI model.
